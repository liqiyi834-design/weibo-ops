# 微信公众号产线

## 定位

微信公众号产线用于中等长度文章草稿，重点服务人文、情感、关系、生活观察和具有账号特色的栏目化表达。

它不是微博短评的加长版，也不是知乎回答的改写版。公众号更重：

- 账号气质和栏目稳定性。
- 具体场景、人物感和情绪递进。
- 有克制的价值判断。
- 可读性、标题、开头和结尾余味。
- 多账号之间的定位差异和风格边界。

边界：

- 不自动发布公众号文章。
- 不自动群发、不自动留言、不自动私信、不自动涨粉。
- 不批量搬运公号文章或复刻外部作者。
- 不把未核实爆料包装成故事。
- 涉及真实人物、家庭、未成年人、医疗、刑案、灾难等高风险内容时，必须降温并保留事实边界。

## 推荐工作流

```text
TopicAsset 综合池 / 人工选题 / 公开热榜
-> 公众号适配评分
-> WeChatArticlePool 公众号文章池
-> 人工选择账号、栏目和文章风格
-> 补充背景资料、案例、个人观察或授权素材
-> 生成文章大纲
-> 人工确认大纲
-> 生成中等长度文章草稿
-> 安全审查和人味评估
-> 草稿箱人工编辑
-> 人工发布
-> 记录 published_url / published_at / performance_note
```

## 推荐模型

建议新增：

- `WeChatArticlePool`
- `WeChatArticleCandidate`
- `WeChatColumnProfile`
- `WeChatArticleDraft`

不要长期复用微博候选池或知乎问题池。公众号文章池应保存公众号特有字段，而不是继续往 `CandidatePoolItem` 塞字段。

## 候选来源

建议来源：

- 从 `TopicAsset` 派生文章选题。
- 人工添加选题、标题、材料和写作动机。
- 从微博/百度/知乎等公开热榜中筛出适合沉淀的慢选题。
- 从风格记忆库、好稿复盘、读者反馈中反推栏目选题。
- 从书影音、城市生活、亲密关系、职场处境、消费体验等低风险长期主题中生成栏目候选。

公众号不应追求所有热点都跟。适合公众号的选题通常需要能从“事件”转成“经验、关系、情绪或价值判断”。

## 评分重点

公众号适配评分不以即时热度为核心。

重点应包括：

- 账号定位适配度。
- 栏目适配度。
- 人文或情感承载力。
- 是否有具体场景、人物处境或生活经验。
- 是否能写出独特观察，而不是公共观点复述。
- 资料和案例是否足够支撑中等长度文章。
- 风险等级和事实可核验程度。
- 标题与开头是否有自然吸引力。
- 是否适合目标账号的情绪强度、句法和结尾方式。

建议字段：

- `topic`
- `proposed_title`
- `account_id`
- `column_id`
- `style_name`
- `fit_score`
- `decision`
- `emotional_core`
- `humanistic_angle`
- `story_entry`
- `outline`
- `required_materials`
- `risk_notes`
- `status`

## 多账号与多风格

多账号只用于少数自有或朋友账号的差异化配置，不用于矩阵号、养号或批量操控。

每个公众号账号建议配置：

- `account_id`
- `positioning`
- `audience`
- `allowed_columns`
- `default_style`
- `allowed_styles`
- `emotion_ceiling`
- `preferred_topics`
- `avoid_topics`
- `signature_moves`
- `forbidden_moves`

人文、情感方向可先设计几类风格：

- `gentle_observer`：温和观察，重共情和余味。
- `sharp_warmth`：有判断但不冷酷，适合关系和生活议题。
- `literary_reflection`：更偏随笔，重场景、隐喻和节奏。
- `urban_memoir`：城市生活、记忆、职业和代际观察。
- `healing_practical`：情绪安放 + 具体建议，避免鸡汤化。

风格记忆库只沉淀抽象写法规则、短例句和禁用点；外部公开文章只作为 `public_reference`，不得保存大段原文或复刻作者。

## 文章结构

中等长度文章建议输出结构：

- `title_options`
- `dek`：副标题或导语。
- `opening_scene`：开头场景或问题。
- `emotional_core`：这篇文章真正处理的情绪。
- `thesis`：核心判断。
- `sections`：3-5 个小节。
- `key_lines`：可保留的金句或判断句。
- `risk_notes`
- `references`
- `body`

推荐长度第一版控制在 1200-2500 字。先追求完整、稳定和可编辑，不追求一次生成成稿。

## 与其他平台的区别

微博：

- 重即时判断和短句冲突。
- 公众号不追快，重沉淀和余味。

知乎：

- 重问题、论证和资料支撑。
- 公众号可以更叙事、更有情绪线，但仍不能虚构事实。

视频：

- 重视觉化和分镜。
- 公众号重语言、结构、栏目和读者停留。
