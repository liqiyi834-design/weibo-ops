# Edge 微博样本采集助手

这个工具不是账号接管，也不是绕过验证。它只做一件事：

在你已经登录的 Edge 微博页面里，读取当前页面上可见的文字内容，并导出为 JSON 样本文件。

它不会读取：

- 密码
- 验证码
- Cookie
- 私信
- 浏览器历史
- 本地存储里的登录令牌

## 使用步骤

### 1. 打开微博页面

用你已登录的 Edge 打开目标页面，例如：

- 热搜话题页
- 某个大 V 主页
- 单条热门微博
- 评论区页面

先手动滚动页面，让你想采集的博文出现在屏幕里。

### 2. 运行采集脚本

打开 Edge 开发者工具：

```text
F12
```

进入 `Console`，复制 `tools\weibo_visible_capture.js` 里的全部内容，粘贴运行。

浏览器会下载一个文件，文件名类似：

```text
weibo_visible_samples_2026-05-08T13-30-00-000Z.json
```

### 3. 移动到 inbox

把下载的 JSON 文件放到：

```text
D:\微博\samples\inbox
```

### 4. 导入样本库

在 PowerShell 里运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Import-WeiboSamples.ps1
```

导入后会生成或追加到：

```text
D:\微博\data\weibo_samples.csv
```

原始 JSON 会移动到：

```text
D:\微博\samples\processed
```

## 推荐采集目标

为了真正完成 200 篇高热博文学习，建议按下面比例采集：

- 热点评论类：40 篇
- 社会新闻类：40 篇
- 财经科技类：30 篇
- 娱乐热点类：30 篇
- 体育电竞类：20 篇
- 生活观察类：20 篇
- 官方媒体/通报类：20 篇

## 每篇最好包含

- 正文
- 发布时间
- 转评赞数据
- 热评前 3 条
- 话题标签
- 账号名

如果页面没有完整导出，就用截图或复制正文补充。

## 安全边界

这个工具是“你在浏览器里主动导出当前可见内容”，不是我远程控制你的 Edge。

账号登录、发布、后台数据仍然由你掌握。
