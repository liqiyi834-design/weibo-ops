# 事实核查与风险分级

目标：让账号“快”但不乱，“犀利”但站得住。

## 发布前事实核查表

| 检查项 | 要求 | 是否通过 |
| --- | --- | --- |
| 事实来源 | 至少 1 个可靠来源 | 是/否 |
| 交叉验证 | 争议事件至少 2 个来源 | 是/否 |
| 时间准确 | 写清楚发生时间或发布时间 | 是/否 |
| 主体准确 | 人名、机构名、地点无误 | 是/否 |
| 状态准确 | 区分传闻、回应、通报、判决、结果 | 是/否 |
| 观点边界 | 没把推测写成事实 | 是/否 |
| 隐私保护 | 没扩散身份证、住址、电话、未成年人信息 | 是/否 |
| 法律风险 | 没有未经证实的定罪式表达 | 是/否 |

## 来源可信度

### A 级来源

- 官方通报
- 法院、警方、监管机构公开信息
- 当事企业官方回应
- 权威媒体原始报道
- 现场视频但需要核验上下文

### B 级来源

- 媒体转载
- 大 V 转述
- 平台热搜页面
- 多个用户发布的相似现场信息

### C 级来源

- 匿名爆料
- 聊天截图
- 单方控诉
- 无出处短视频
- 二手剪辑

使用规则：

- A 级可作为主事实。
- B 级只适合作为线索。
- C 级不能直接作为事实发布。

## 风险表达替换

不要写：

```text
某某就是骗子。
某某肯定违法。
这家公司故意坑消费者。
```

可以写：

```text
目前公开信息还不足以给个人定性。
如果通报属实，争议点主要在规则执行。
这件事暴露出平台售后机制里的灰区。
```

## 高风险选题安全写法

高风险不是不做，而是换一种更稳的写法：

- 可以追热点，但必须先标清事实来源。
- 不写未经确认的细节。
- 不给具体个人定性。
- 不扩散隐私、血腥、侮辱性内容。
- 优先做“通报翻译”“信息梳理”“规则分析”“影响分析”。
- 对仍在变化的事件，明确写“目前能确认的是”和“仍需后续确认的是”。

```text
目前能确认的是：
1.
2.
3.

仍需后续确认的是：
1.
2.

所以这条热搜现在更适合讨论规则，不适合急着给个人下结论。
```

## 不碰红线

- 不扩散血腥、裸露、隐私图片。
- 不引导攻击个人。
- 不发布未成年人身份信息。
- 不对司法案件抢先定性。
- 不把民族、地域、职业群体整体污名化。
- 不编造消息源。
