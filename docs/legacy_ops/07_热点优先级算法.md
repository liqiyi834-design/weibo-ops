# 热点优先级算法

目标：把“短期反复出现、长期周期性出现、公众讨论价值高”的新闻识别出来，优先制作发布。

## 核心判断

一条新闻是否值得优先做，不只看当天排名，还要看它是不是反复出现。

如果同类新闻在以下时间窗口内多次出现，就判定为高热度候选：

- 1 天内
- 3 天内
- 7 天内
- 15 天内
- 30 天内
- 90 天内
- 180 天内
- 365 天内

说明：你说的“半月”出现了两次，我这里把后一处按“半年”处理，也就是 180 天。

## 类似新闻判定

优先使用 `event_key` 判断。只要 `event_key` 一样，就归为同一类新闻。

例如：

- `榴莲仅退款买家被行拘`
- `榴莲仅退款买家发声`
- `榴莲遭仅退款商家称希望公开道歉`

可以统一写成：

```text
event_key = 榴莲仅退款纠纷
```

如果 `event_key` 还没来得及填，可以用 `tags` 辅助判断。同一类新闻至少应共享 2 个以上关键标签。

例如：

```text
tags = 仅退款;消费者纠纷;平台治理;榴莲
```

## 分数结构

最终优先级分数：

```text
priority_score =
当天热度分
+ 复现分
+ 新鲜度分
+ 公共价值分
+ 双榜加权分
+ 时段匹配分
- 风险扣分
```

## 复现分权重

越近的重复出现，权重越高。

| 时间窗口 | 权重 | 解释 |
| --- | ---: | --- |
| 1 天 | 35 | 当天反复出现，极适合快评 |
| 3 天 | 25 | 短期连续发酵 |
| 7 天 | 18 | 一周内持续讨论 |
| 15 天 | 14 | 半月内仍有生命力 |
| 30 天 | 10 | 月度社会议题 |
| 90 天 | 7 | 季度级长期议题 |
| 180 天 | 5 | 半年周期复现 |
| 365 天 | 3 | 年度周期复现 |

每个窗口按出现次数计分，但会封顶，避免一个话题刷屏后把系统带偏。

为了避免同一批复现同时落入多个时间窗口导致分数膨胀，复现分总分最高封顶 80 分。

## 双榜加权分

同一个词条如果同时进入微博热搜榜和文娱榜，优先级上调。原因是：热搜榜代表全站公共热度，文娱榜代表娱乐传播入口和路人讨论素材，双榜重合更容易扩散。

| 双榜情况 | 加分 | 处理 |
| --- | ---: | --- |
| 同时出现在热搜榜和文娱榜 | +12 | 进入优先候选 |
| 热搜榜前 10，文娱榜前 30 | +18 | 建议当天发 |
| 文娱榜前 10，热搜榜前 30 | +18 | 建议当天发 |
| 热搜榜前 10，文娱榜前 10 | +25 | S 级优先，尽快发 |

记录字段建议：

```text
charts = 热搜;文娱
hot_rank = 热搜榜排名
entertainment_rank = 文娱榜排名
source = weibo_hot;weibo_entertainment
```

如果暂时没有具体排名，但确认双榜都上了，按 +12 处理。

## 时段匹配分

同一个热点在早、中、晚的传播效果不同，所以 S/A/B 评级必须结合当前发布时间。

| 时段 | 加分方向 | 降级方向 |
| --- | --- | --- |
| 早间 | 昨夜后续、明确事实、社会/财经影响 | 长篇娱乐瓜、低信息量情绪题 |
| 午间 | 娱乐争议、职场、消费、轻社会 | 需要大量背景的国际/政策题 |
| 下班 | 消费权益、工作透支、家庭关系、食品健康 | 宏观空话、软节日文 |
| 夜间 | 文娱争议、关系话题、强反差社会新闻 | 低热生活题、无争议题 |

人工判断时：

- 当前时段高度匹配：+15。
- 一般匹配：+5。
- 明显不匹配：-10。

脚本总分只做基础参考，最终发布等级以“基础分 + 时段匹配 + 当前榜单变化 + 用户数据反馈”为准。

## 优先级等级

| 分数 | 等级 | 处理方式 |
| ---: | --- | --- |
| 80+ | S | 必做，优先当天发 |
| 60-79 | A | 建议当天发 |
| 40-59 | B | 可做，适合做储备稿 |
| 20-39 | C | 观察 |
| 0-19 | D | 暂不做 |

## 选题策略

每天从 S/A 级里优先选：

- 有公共价值的社会新闻
- 能讲清楚利益链或制度逻辑的新闻
- 有明确反转或后续进展的新闻
- 同类事件反复出现，能做成系列观察的新闻

谨慎选择：

- 只有明星八卦、没有信息增量的话题
- 未核实爆料
- 高法律风险或高隐私风险话题
- 纯情绪对立、无法提供理性增量的话题

策略更新：谨慎不等于不做。只要热度足够高，高风险话题也可以做，但必须降级写法：

- 不写未经证实细节
- 不做个人定性
- 不扩散隐私
- 用事实梳理、通报翻译、影响分析替代情绪站队

实时榜单强制规则：

- 榜首热点必须优先参与。
- 带“新”“热”等标识的热点必须进入候选池。
- 同一词条同时上热搜榜和文娱榜，必须进入候选池；双榜都靠前时优先于单榜同热度词条。
- 除非无法合法合规表达，否则不跳过榜首和新热视频事件。

## 每日使用方式

1. 把当天热搜追加到 `data/news_history.csv`。
2. 给同类新闻填同一个 `event_key`。
3. 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Get-HotPriority.ps1
```

4. 查看 `output\hot_priority_日期.csv`。
5. 优先制作 S/A 级新闻。
