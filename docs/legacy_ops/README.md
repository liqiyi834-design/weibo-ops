# 早期运营素材归档

本目录保存项目早期的微博人工运营资料、模板、样本分析和增长记录。它们是历史知识源和 RAG/Prompt 参考材料，不是当前开发或部署入口。

当前开发交接入口请看：

- `../../AGENTS.md`
- `../README.md`
- `../agent_handbook/README.md`

## 使用方式

- 写作风格、爆款结构、风险边界等内容可作为 RAG 知识源或人工参考。
- 运营排期、选题库、增长看板属于历史模板，后续如需恢复使用，应先确认字段是否仍符合当前工作台。
- 不要把这些归档文档视为当前产品/技术权威；如与 `docs/agent_handbook/` 冲突，以当前 handbook 为准。

- `04_人设与风格规则.md`：表达风格模板和风格化改写规则。
- `06_草稿生成提示词.md`：早期草稿生成 Prompt 来源。
- `08_高热博文公开样本研究.md`：高互动样本研究。
