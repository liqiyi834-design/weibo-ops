# 高互动正文分析标准

目标：不再优先采集评论区，而是围绕“发布时点语境 + 正文内容 + 点赞评论转发量”分析高互动博文。

这里的“发布时间/日期”不是只记一个时间戳，而是要判断：这条博文发布时，外部环境里正在发生什么高相关事件。

## 核心样本字段

每条样本尽量记录：

- 账号名
- 账号领域
- 发布时间或日期
- 发布时点相关事件
- 当时热搜/节点
- 事件阶段
- 博文链接
- 正文内容
- 转发量
- 评论量
- 点赞量
- 是否带话题
- 是否带图片/视频
- 内容类型
- 可学习点

## 高参考价值样本

优先分析：

- 点赞高
- 评论高
- 转发高
- 三者都高
- 同账号里明显高于平均水平
- 同话题下明显高于其他博文
- 正好卡在关键事件节点发布

## 发布时点语境

每条样本必须尽量补充：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| context_event | 发布时对应的高相关事件 | 世乒赛男团中韩对阵 |
| event_stage | 事件阶段 | 赛前/赛中/赛后/通报后/反转后/节日前/政策发布后 |
| related_hotwords | 当时相关热词 | 王楚钦扛住了;国乒男团进四强 |
| timing_advantage | 时间优势 | 抢在结果后10分钟;赛前汇总;通报后第一波解释 |
| why_now | 为什么这个时间点适合发 | 用户正在查赛程/等结果/表达情绪/寻找解释 |

## 时点类型

| 时点 | 适合内容 | 爆发原因 |
| --- | --- | --- |
| 事件前 | 预告、清单、赛程、看点 | 用户需要准备和收藏 |
| 事件中 | 实时进展、比分、现场变化 | 用户需要即时信息 |
| 结果后 | 总结、复盘、情绪释放 | 用户需要结论和表达 |
| 通报后 | 信息梳理、规则解释 | 用户需要确认事实 |
| 反转后 | 前后对比、判断修正 | 用户需要重新理解 |
| 节日前后 | 消费、出行、情绪、生活 | 用户有共同场景 |
| 争议发酵期 | 多方观点、边界分析 | 用户有分歧和评论欲 |

## 内容类型分类

| 类型 | 特征 | 学习重点 |
| --- | --- | --- |
| 快评 | 直接表达观点 | 开头判断、立场边界 |
| 信息汇总 | 赛程、名单、时间线、清单 | 结构化表达、收藏价值 |
| 生活共鸣 | 打工人、关系、情绪、日常 | 代入感、评论钩子 |
| 消费观察 | 花钱、购物、服务、平台规则 | 普通人利益点 |
| 热点科普 | 政策、健康、科技、财经 | 人话解释能力 |
| 娱乐传播 | 明星、综艺、名场面 | 轻情绪、粉丝接话 |
| 结果复盘 | 比赛、判决、发布会、事件后续 | 结论提炼、转折点 |

## 互动权重

默认综合互动分：

```text
互动分 = 点赞 * 1 + 评论 * 3 + 转发 * 5
```

解释：

- 点赞代表认同或顺手反馈。
- 评论代表讨论意愿。
- 转发代表传播价值，权重最高。

## 分析维度

每条高互动样本重点看 8 件事：

1. 第一秒是否有明确钩子。
2. 是否绑定热点词。
3. 是否有具体事实或信息增量。
4. 是否有鲜明但安全的观点。
5. 语言是否像真人。
6. 是否容易引发评论。
7. 是否有收藏/转发价值。
8. 是否卡住了关键事件时点。
9. 是否能迁移到“今日有话直说”。

## 我们要重点学习的文本

优先学习：

- 高赞正文的开头
- 高评正文的结尾问题
- 高转正文的信息结构
- 高互动正文的语气节奏
- 同一账号里爆文和平文的差异

暂时不重点学习：

- 评论区楼中楼
- 粉丝互撕
- 表情包刷屏
- 低质量玩梗
- 仅靠图片/视频爆的内容

## 对账号的应用

每天复盘时，从已发内容里选：

- 阅读最高 1 条
- 评论最高 1 条
- 点赞最高 1 条
- 转发最高 1 条

然后拆：

```text
为什么这条更容易被看见？
它卡住了什么事件节点？
如果提前/延后 1 小时，效果会不会变差？
为什么这条更容易被评论？
为什么这条更容易被转发？
下一条如何复制这个结构？
```
