# 评论区互动 SOP

目标：让评论区从“没人说话”变成“用户知道该怎么接话”。

## 发文前设计评论钩子

每条微博发布前，必须选择一种评论钩子。

| 钩子类型 | 适合内容 | 结尾句式 |
| --- | --- | --- |
| 站队型 | 公共争议、消费纠纷 | 你觉得这次是重了，还是轻了？ |
| 经历型 | 职场、消费、生活新闻 | 你遇到过类似情况吗？ |
| 补充型 | 娱乐、科技、体育 | 还有哪个细节你觉得被忽略了？ |
| 预测型 | 商业、科技、国际 | 你觉得下一步会怎么发展？ |
| 纠错型 | 科普、政策、通报 | 我漏掉了哪个关键事实？ |
| 选择型 | 产品、影视、人物 | 如果是你，会选 A 还是 B？ |

## 评论区前三条

发布后 10 分钟内，自己准备 3 条评论，用来给讨论定调。

### 第一条：补充事实

```text
补一个细节：目前能确认的是 X，暂时不能确认的是 Y。别急着把传闻当结论。
```

### 第二条：抛出分歧

```text
这事评论区估计会分两派：一派觉得该重罚，一派觉得规则也要更清楚。你站哪边？
```

### 第三条：轻松接梗

```text
今天的互联网又给我上了一课：热搜不是瓜田，是社会学速成班。
```

## 高互动回复方式

### 回复赞同者

不要只回“对”。要顺手加一层观点。

```text
是这个意思。很多人只看结果，其实真正值得看的是规则怎么被执行。
```

### 回复反对者

不要急着吵，先把对方观点复述准确。

```text
你这个角度有道理，你担心的是处罚尺度会不会被扩大化。我更关心的是平台规则能不能提前讲清楚。
```

### 回复补充信息的人

要鼓励用户继续补充。

```text
这个补充很关键，感谢。这个细节如果属实，整件事的判断会更完整。
```

### 回复抬杠的人

短、稳、别陷进去。

```text
可以不同意，但别跳过事实直接扣帽子。
```

## 评论区维护节奏

- 发布后 0-10 分钟：补 3 条自评，拉起第一波互动。
- 发布后 10-30 分钟：回复高质量评论，优先回复能展开讨论的。
- 发布后 30-60 分钟：挑 1 条争议评论做二次补充。
- 发布后 2-4 小时：如果话题还在热搜，发一条后续微博接住流量。

## 禁止操作

- 不诱导攻击具体个人。
- 不引导网暴、人肉、泄露隐私。
- 不用虚假提问骗评论。
- 不和低质量攻击长线争吵。
- 不刷屏式自评，避免像营销号。

## 评论区质量判断

一条微博的评论区好不好，不只看数量，还看：

- 是否有人讲自己的经历
- 是否有人补充事实
- 是否出现观点分歧
- 是否有人转发给朋友讨论
- 是否能产生第二条后续选题
